# 🧩 DOM Manipulation

Exercício focado em praticar a manipulação do DOM (Document Object Model) com JavaScript puro, aplicando eventos, seletores e alterações dinâmicas em elementos da página.

## ✨ Demonstração

> O projeto interage diretamente com a página HTML por meio de scripts JavaScript que manipulam o DOM.

## 💡 Sobre

Neste exercício, foram criadas funcionalidades que alteram dinamicamente o conteúdo de uma página HTML usando JavaScript, por meio da manipulação de elementos com seletores, eventos e propriedades do DOM.

O foco foi aplicar conceitos fundamentais de interatividade e atualização de conteúdo em tempo real.

## 🛠️ Habilidades desenvolvidas

- Manipulação do DOM com JavaScript
- Seleção e modificação de elementos HTML
- Criação e remoção de elementos dinamicamente
- Aplicação de eventos como `click`, `input`, entre outros

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6+

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/exercise-dom-manipulation.git
```

2. Acesse a pasta do projeto

```bash
cd exercise-dom-manipulation
```

3. Instale as dependências

```bash
npm install
```
